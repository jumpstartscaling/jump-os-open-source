# Security policy

Please do not open a public issue for credentials, private endpoints, customer data, or an exploitable vulnerability.

Until a dedicated private security contact is published, report sensitive issues privately to the project maintainer through the Jumpstart Scaling GitHub account. Include a concise description, affected artifact, reproduction details that do not expose secrets, and suggested containment.

This repository is an architectural research project. Nothing in it grants permission to test or access systems that you do not own or have explicit authorization to assess.

## Project boundary

The public repository contains specifications, documentation, and fictional examples. It does not operate a hosted Jump OS service and does not include Jumpstart Scaling production infrastructure, credentials, tenant data, private routes, or deployment topology. A vulnerability in an adopter's implementation should be reported to that adopter unless it is caused by a defect in a public contract or example here.

The project currently has no dedicated security email or private advisory service. Until one is published, use the private contact path available through the `jumpstartscaling` GitHub account. Do not include secrets or private infrastructure details in the report itself.
