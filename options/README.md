# Jump OS implementation options

Jump OS is vendor-neutral. These documents describe decision factors, not mandatory product selections. Choose the smallest architecture that satisfies the case's authority, durability, evidence, and rollback requirements.

- [Identity and workload authentication](identity-and-workload-auth.md)
- [Policy engines](policy-engines.md)
- [Task state and durability](task-state-and-durability.md)
