# Jump OS: Governed Enterprise Agentic Architecture

## Summary

This dataset-style publication contains the public architectural research materials for Jump OS, an open framework for bounded, inspectable, and durable enterprise agent execution.

## What is included

- The architectural research paper.
- A fictional execution-receipt example.
- A JSON Schema starter for receipt structure.
- Contribution and security guidance.

## Intended use

Use these materials to discuss agent authority, policy-as-code, durable task ownership, audit receipts, rollback, MCP/A2A adapters, and the difference between documented intent and runtime proof.

## Important limitations

This is not a production dataset, telemetry export, customer dataset, credential bundle, or claim of a complete reference implementation. Identifiers and endpoints in the example are fictional. No private Jumpstart Scaling infrastructure is included.
